# Assets

This directory contains public-facing architecture assets for the portfolio repository.

- `architecture_public.tex`: standalone TikZ source for the public system architecture
- `architecture_public.pdf`: generated figure, if local LaTeX tooling is available
- `architecture_public.png`: generated README-friendly image, if local conversion tooling is available

The diagram is intentionally high level and omits research-specific methods, formulas, datasets, and experiment details.
