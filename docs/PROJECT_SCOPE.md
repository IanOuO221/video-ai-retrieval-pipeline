# Project Scope

This repository is a public portfolio version of an ongoing master's thesis research project. It is designed to communicate system design, engineering experience, and selected public-safe components without exposing unpublished research details.

## Public

The following topics are appropriate for this public repository:

- High-level system architecture
- Project motivation
- Generic video processing
- Object detection
- Multi-object tracking
- Selected non-sensitive demos
- High-level VLM and retrieval workflow
- Selected engineering documentation
- Modular Python project organization

## Private Thesis Material

The following materials are intentionally excluded:

- Research-specific utility formulations
- Unpublished selection algorithms
- State-aware representations
- Supervision construction
- Full experiments
- Ablations
- Private datasets
- Unpublished thesis writing
- Internal research documentation

This public repository does not provide mathematical definitions, implementation details, or reconstruction guidance for private thesis methods.

## Publication Boundary

The goal is to show practical experience with Video AI, Computer Vision, Machine Learning, VLM-based understanding, and semantic retrieval while protecting unpublished academic work.

Before publishing updates, new files should be reviewed to ensure they do not disclose private datasets, local paths, credentials, unpublished formulas, or research-specific implementation details.
